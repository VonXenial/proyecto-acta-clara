## 🏗️ RESUMEN DE COMPONENTES
Se ha implementado el motor de normalización de modismos chilenos:
- **Servicio:** `Normalizer` con carga de diccionarios JSON.
- **Diccionario:** `modismos_es_CL_v1.0.json` con 100+ términos.
- **Modelado:** `ModismoDetectado` para trazabilidad de cambios.

## ✅ CRITERIOS DE ACEPTACIÓN
- [x] El motor detecta modismos multi-palabra (ej: "al tiro").
- [x] Se soporta la sustitución por términos formales (ej: "inmediatamente").
- [x] Se preserva la posición (inicio/fin) para resaltado en UI.
- [x] Los tests unitarios en `test_p2_normalizer.py` pasan al 100%.
