# AUDITORÍA VERSIÓN v0.2 (P1) - MOTOR STT

## ⚙️ Especificaciones
- **Modelo:** faster-whisper (small-int8)
- **Audio:** 16kHz, Mono, WAV (vía pydub)
- **Binarios:** FFmpeg release-essentials local

## ❌ Errores y Dificultades
1. **Python 3.14 Conflict:** La librería `torch` no tenía wheels para Python 3.14. Se solucionó permitiendo versiones `>2.9.0` en lugar de fijas.
2. **FFmpeg Path:** En Windows, pydub fallaba al encontrar FFmpeg. Se implementó `os.path.abspath` para forzar la ruta local.

## ⚠️ Limitaciones
- **Consumo RAM:** El modelo 'small' consume ~1.5GB de RAM. Equipos con <4GB podrían fallar.
- **Inferencia CPU:** Sin GPU (CUDA), audios largos (1h) pueden tardar hasta 30-40 min.

## 🔍 Observaciones para Debugger
- Vigilar el uso de memoria en el hilo `TranscriptionWorker`.
